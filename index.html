          USER MANUAL

          Agent 使用说明书

          陌生人只阅读本节，也能知道它是什么、怎么使用、能交付什么，以及何时必须人工介入。

          它是什么

          一个机会研究 Agent：输入风向标或业务观察，交付事实/推断分层、用户痛点、最大风险、7 天实验、成功指标、停止条件和内容选题。

          省什么人工

          人工整理估算约 45–90 分钟；Agent 生成初稿约 1–3 分钟，人工复核约 5–10 分钟。参考：45–90 分钟 → 6–13 分钟。连续记录 10 次后更新正式均值。

          用了什么工具

          • Codex：设计岗位、工作流、Profile、测试和公开网站。
          • SCYS MCP：在授权环境内只读检索和读取真实主题。
          • Puter.js + GPT-5.4 nano：承载公开网页的用户授权模型调用，不保存模型密钥。
          • Vercel：托管公开网站和输入校验接口。
          • Hermes / 飞书 Bot：承载个人工作环境中的独立 Agent 入口。

          输入与触发

          1. 打开本页顶部“直接使用智能体”。
          2. 填写标题和至少 30 字的正文、摘要或业务观察。
          3. 选择最想判断的问题。
          4. 点击“开始拆解”；首次使用按提示完成 Puter 登录/授权。
          5. 检查页面返回的八类结构化结果。

          标准输出

          ✓ 已确认事实
          ✓ 判断与推断
          ✓ 目标用户与痛点
          ✓ 最大风险假设
          ✓ 7 天验证实验
          ✓ 成功指标与停止条件
          ✓ 内容选题角度
          ✓ 待人工确认事项

          注意事项与人工介入

          • 公开版不会自动读取 SCYS 会员内容，必须粘贴自己有权处理的材料。
          • 结果不是投资、法律、医疗或收益承诺，关键事实、成本与合规必须人工复核。
          • 不自动收藏、点赞、评论、报名、付费、联系他人、写入知识库或发布。
          • 不要提交密码、密钥、Cookie、个人隐私或无权处理的内容。
          • 首次模型调用需要 Puter 用户授权，AI 用量由使用者自己的 Puter 账户承担。
